# Fluxo v1.1

## Entrada unica

Todo trabalho comeca em `L1_TRIAGE`.

## Fluxo para projeto novo

1. Criar ou revisar `agent-operating-rules.md`.
2. Brainstorming + Grill de Escopo + Pre-PRD.
3. Criar PRD mestre.
4. Revisar criticamente o PRD.
5. Melhorar PRD.
6. Transformar PRD em plano de implementacao.
7. Sprint 0.
8. Sprint 00B, se nao houver testes.
9. Executar sprint com coder economico usando guardrails.
10. Gerar evidencias.
11. Auditoria.
12. Correcao pos-auditoria.
13. Validacao pos-correcao.
14. Retrospectiva.
15. Atualizar backlog/PRD v1.1, se necessario.

## Fluxo para projeto existente

1. Triagem.
2. Analise Brownfield.
3. Criar Pre-PRD ou atualizar PRD com base no estado real.
4. Seguir fluxo normal a partir do PRD.

## Fluxo para projeto retomado

1. Triagem.
2. Ler `HANDOFF.md`.
3. Ler `CURRENT_STATE.md`.
4. Ler `DECISIONS.md` e `CHANGELOG.md`.
5. Recomendar ponto de retomada.

## Fluxo de falha

1. Interromper sprint.
2. Acionar rollback.
3. Registrar falha.
4. Reverter com seguranca.
5. Validar estado restaurado.
6. Atualizar handoff.
7. Replanejar antes de tentar novamente.
